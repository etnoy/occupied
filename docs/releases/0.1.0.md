Occupied's first installable release includes the household editor, seeded daily planner, durable runtime and managed configuration.

- GUI storage, YAML snapshot import and authoritative read-only file setup, including unattended singleton bootstrap.
- Validated/idempotent `occupied.reload`, debounced atomic-file change detection, explicit source switches and HA Repairs. Invalid updates retain the running program; invalid startup stays inactive.
- Bundled editor, timeline, isolated previews and dry run; native state conditions, generic actions, gradual handover, and explicit owned activity cleanup/restart recovery.
- HACS `occupied.zip`, standalone CLI wheel/source distribution and SHA256 checksums. No frontend build or additional runtime process is needed.
- CLI validation, previews, reviewed ID migration, program-day `--date today`, and token-file authenticated reload; Puppet/manual/HACS deployment and upgrade/uninstall guides.

Verified against HA 2026.9.3 and 2026.9.4 on Python 3.14.8, with real HA APIs/storage/timers and virtual device handlers. Browser workflows cover desktop and 390px layouts. Physical-device timing and a hardware soak remain deployment acceptance work.

Install instructions: https://github.com/etnoy/occupied/blob/main/docs/installation.md

Managed/Puppet configuration: https://github.com/etnoy/occupied/blob/main/docs/managed-configuration.md

The zip extracts directly into `custom_components/occupied/`. GUI/store schema version 1 remains supported; no manual storage migration is required. Back up HA, disable permission while replacing integration files, and inspect dry run before enabling live operation.
